# 12. 発表時の機能

## スピーカーノート

`s` キーでスピーカービュー（発表者だけが見る画面。本編のミラー・時計・ノートを表示）を開く。
ノートは `speaker-note` アクションで、実行された瞬間にビューへ流し込まれる。

{pause scroll}
```markdown
{speaker-note}
自分に付けたノート。

{#note-1}
表示はしないが、ここにノートを書いておく。

{speaker-note=note-1}
別の場所で実行するノート（内容と実行タイミングを分離できる）。

{#title-with-note}
# 見出し

{speaker-note up=title-with-note}
見出しの表示と同時にノートも切り替える。
```

{.remark pause scroll}
3 つ目の書き方（他のアクションと同時に `speaker-note` を書く）が実用上は一番多い。
見出しが変わるたびにノートも自動で切り替わる。

{pause up}

## 目次

右下のステップ番号（このデッキでは `_shared/ja.css` が読みやすいサイズに調整している）を
クリックするか `t` キーで、見出し構造から作られる目次が開く。

{pause up}

## 描画とその記録

発表中にマウス／ペンで直接書き込める。ツールは 1 文字キーで切り替える：

| キー | ツール |
| --- | --- |
| `p` | ペン |
| `h` | ハイライター |
| `e` | 消しゴム |
| `x` | カーソル |
| `Shift+X` | 描画を全消去 |

`Shift+R` で「録画マネージャ」を開くと、筆跡をタイムラインとして記録し `.draw` ファイルに
保存できる（9 章参照）。保存済みの録画は `draw` アクションで再生する。

{pause up}

## ショートカット一覧

| キー | 動作 |
| --- | --- |
| `↓` `→` `Space` `PageDown` | 次のステップ |
| `↑` `←` `PageUp` | 前のステップ |
| `s` | スピーカーノートを開く |
| `i` `j` `k` `l` | スクロール窓の手動移動 |
| `z` / `Shift+Z` | ズーム / ズーム解除 |
| `t` | 目次を開く |
